# Aethelgrad art and animation prompt pack

These prompts are for original concept and production references. They describe broad visual attributes without requesting copied characters, logos, names, maps, or ripped assets from existing games.

## Hero character

Create an original high-end 3D anime action-survival RPG hero for Aethelgrad: Wild Horizons – Crafting. Show an adult wilderness adventurer in layered leather-and-cloth survival armor, compact stamina backpack, hunting knife, glowing teal bow, practical boots, dark auburn wind-swept hair, amber scarf, and a clear readable silhouette. Provide front, back, side, three-quarter, and facial-expression views on a neutral studio background. Use polished stylized PBR materials with controlled cel-shaded accents. No text, no logo, no existing franchise design.

## Companion creature

Create an original cute-but-capable fox-like forest companion with cream fur, moss-green markings, luminous cyan crystal antlers, golden eyes, leather travel harness, and tiny utility satchel. Provide a full-body model reference, turn-around, facial expressions, sitting, running, alert, scared, sleeping, gathering, and companion-follow poses. Keep the creature distinct from all existing game creatures.

## Forest key art

Create an original open-world forest valley with layered foliage, mossy ruins, river, cliffs, distant mountains, a camp with bedroll and crafting bench, dawn and night lighting variants, readable traversal paths, and strong depth. Produce separate environment concept passes for lighting, weather, collision landmarks, resource nodes, enemy patrol spaces, and boss arena readability.

## Biome set

Create an original biome grid containing a temperate forest, crystal cave, desert oasis, snowy mountain pass, coastal marsh, volcanic ravine, and ancient ruin interior. Keep a unified palette language and material response so the world feels like one game while each biome has its own weather, resource families, wildlife, hazards, and music state.

## Modular building set

Create a modular 3D building kit with foundations, floors, stone and wood walls, windows, doors, stairs, roofs, supports, storage, crafting stations, beds, defensive pieces, lighting, and repair variants. Show snapping points, pivot conventions, collision intent, LOD intent, and damage states. Design every piece for gameplay readability on a mobile screen.

## Animation set

Create an original animation plan for the hero: idle, walk, jog, sprint, strafe, stop, turn-in-place, jump, fall, landing, crouch, slide, dodge, light combo steps one through three, heavy attack, bow draw/release, gather, craft, climb, swim, take damage, stagger, downed, revive, sleep, wake, emote, and weapon-swap transitions. Use root-motion only where the server can validate the result; otherwise use in-place clips with authoritative movement.

## UI visual direction

Design a landscape mobile UMG HUD with translucent left virtual joystick, right look pad, attack and heavy-attack buttons, jump, dodge, sprint/slide, weapon quick slots, interaction prompt, survival bars, minimap, inventory, crafting, settings, login, and disabled-state treatment. Use deep forest teal, warm amber, pale cream, and cyan accent colors. Keep all labels readable at common phone sizes and reserve safe-area margins.
