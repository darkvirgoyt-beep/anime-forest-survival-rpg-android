# Aethelgrad cinematic online login direction

The login screen uses an original dark-fantasy composition intended for a landscape Android device. Its hierarchy is a small gold rune crest, the Aethelgrad title, the line “WILD HORIZONS • CRAFTING,” an online-world status message, a region selector, and a single primary Google Play sign-in action. The presentation uses deep midnight blue, charcoal, muted forest green, parchment white, and restrained antique-gold accents.

The world backdrop combines a packaged original raster landscape at `app/src/main/res/drawable-nodpi/aethelgard_login_cinematic_background.png` with a procedural fallback vignette made from layered gradients, distant ridge silhouettes, mist bands, rune particles, and an abstract campfire glow. The raster asset was generated specifically for Aethelgrad and contains no people, text, logos, or borrowed IP. It must not reproduce the supplied reference’s hero character, castles, banner, logo geometry, background landscape, exact copy, or control placement. The user-provided image is treated only as guidance for a premium cinematic mood, centered hierarchy, and the contrast between warm gold UI elements and a dark world scene.

Release behavior remains online-only. The primary action is **CONTINUE WITH GOOGLE PLAY**. There is no player-facing guest entry. The consent checkbox must be acknowledged before initiating sign-in. The lower trust strip communicates Cloud Save, Account Link, Secure Sessions, and Co-op Ready; it is informational and does not claim that unconfigured production services are live. Region selection is enabled only when an online server record is available.

Authentication outcomes are displayed in the same central status zone: signing in, authenticated, denied, configuration required, session expired, network unavailable, and general error. The settings control exposes existing audio and control settings without providing a path around the online authentication requirement.

The login overlay is sign-in only. Once the backend reports `AUTHENTICATED`, it is removed automatically and replaced by a separate character-setup stage. The Drive error evidence recorded on 2026-08-23 showed the prior defect: a visible `PREPARE CHARACTER` button only updated status text after account verification and never navigated. The repaired login panel contains no character or art-library controls; character name and cosmetic selectors appear only after the verified-session transition.

For the current **test-distribution APK only**, the Google Cloud Android OAuth client must use package `com.darkvirgoyt.aethelgrad` and the SHA-1 from the exact GitHub signing-certificate artifact. A future Google Play App Signing release certificate requires its own OAuth SHA-1 registration; do not treat a test key as a production Play signing key.
