# Aethelgard cinematic online login direction

The login screen uses an original dark-fantasy composition intended for a landscape Android device. Its hierarchy is a small gold rune crest, the Aethelgard title, the line “WILD HORIZONS • CRAFTING,” an online-world status message, a region selector, and a single primary Google Play sign-in action. The presentation uses deep midnight blue, charcoal, muted forest green, parchment white, and restrained antique-gold accents.

The world backdrop is an original procedural vignette made from layered gradients, distant ridge silhouettes, mist bands, rune particles, and an abstract campfire glow. It must not reproduce the supplied reference’s hero character, castles, banner, logo geometry, background landscape, exact copy, or control placement. The user-provided image is treated only as guidance for a premium cinematic mood, centered hierarchy, and the contrast between warm gold UI elements and a dark world scene.

Release behavior remains online-only. The primary action is **CONTINUE WITH GOOGLE PLAY**. There is no player-facing guest entry. The consent checkbox must be acknowledged before initiating sign-in. The lower trust strip communicates Cloud Save, Account Link, Secure Sessions, and Co-op Ready; it is informational and does not claim that unconfigured production services are live. Region selection is enabled only when an online server record is available.

Authentication outcomes are displayed in the same central status zone: signing in, authenticated, denied, configuration required, session expired, network unavailable, and general error. The settings control exposes existing audio and control settings without providing a path around the online authentication requirement.
