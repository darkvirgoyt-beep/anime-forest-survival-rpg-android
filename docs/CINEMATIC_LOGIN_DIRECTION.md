# Aethelgrad cinematic online login direction

The login screen uses an original dark-fantasy composition intended for a landscape Android device. Its hierarchy is a small gold rune crest, the Aethelgrad title, the line “WILD HORIZONS • CRAFTING,” a world status message, a region selector, a primary Google Play sign-in action, and a secondary guest-local action. The presentation uses deep midnight blue, charcoal, muted forest green, parchment white, and restrained antique-gold accents.

The world backdrop combines a packaged original raster landscape at `app/src/main/res/drawable-nodpi/aethelgard_login_cinematic_background.png` with a procedural fallback vignette made from layered gradients, distant ridge silhouettes, mist bands, rune particles, and an abstract campfire glow. The raster asset was generated specifically for Aethelgrad and contains no people, text, logos, or borrowed IP. It must not reproduce the supplied reference’s hero character, castles, banner, logo geometry, background landscape, exact copy, or control placement. The user-provided image is treated only as guidance for a premium cinematic mood, centered hierarchy, and the contrast between warm gold UI elements and a dark world scene.

Release behavior has two explicit paths. **SIGN IN WITH GOOGLE** starts the hosted cloud-world and co-op path, and the consent checkbox must be acknowledged before that provider flow begins. **CONTINUE AS GUEST** starts a local world without Gmail or a server login; the guest can use local exploration, combat, gathering, crafting, companions, camp, and world features, but hosted multiplayer and cloud worlds remain unavailable until Google login. The lower trust strip communicates Cloud Save, Account Link, Secure Sessions, and Co-op Ready for the Google path; it does not claim that unconfigured production services are live. Region selection is used by hosted services and is not required for guest local entry.

Authentication outcomes are displayed in the same central status zone: signing in, authenticated, denied, configuration required, session expired, network unavailable, and general error. The settings control exposes existing audio and control settings without changing either account path or granting a guest hosted-multiplayer bypass.

The login overlay offers both account paths. Once Google reports `AUTHENTICATED` or the local guest session becomes ready, it is removed automatically and replaced by a separate character-setup stage. The Drive error evidence recorded on 2026-08-23 showed the prior defect: a visible `PREPARE CHARACTER` button only updated status text after account verification and never navigated. The repaired login panel contains no character or art-library controls; character name and cosmetic selectors appear only after the verified-session transition.

For the current **test-distribution APK only**, the Google Cloud Android OAuth client must use package `com.darkvirgoyt.aethelgrad` and the SHA-1 from the exact GitHub signing-certificate artifact. A future Google Play App Signing release certificate requires its own OAuth SHA-1 registration; do not treat a test key as a production Play signing key.
