09 / Interface

The Android HUD makes system state testable

Readable status instrumentation, co-op state, map orientation, and consistent profile identity.

System Status

Exposes biome, phase, weather, camera, map, tower, health, stamina, hunger, and resources directly on-screen for immediate feedback.

Co-op Telemetry

Adds room code, participant count, tower revision, boss health, and weather synchronization to the status line when connected.

Map Orientation

The map overlay remains a quick orientation instrument with region bands and markers, rather than a replacement for world exploration.

Profile Identity

Gold AETHELGRAD profile identity appears at install, during setup, and in the game HUD.
