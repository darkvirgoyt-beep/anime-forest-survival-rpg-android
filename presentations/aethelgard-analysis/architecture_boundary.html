PRODUCE THE 3D GAME IN UNREAL.

The repository is healthiest when each runtime has a distinct job. The Android build proves touch input and deterministic gameplay rules; Unreal carries the player-facing 3D production burden.

Android

Contract prototype

  • ■Kotlin activity, Compose overlay, touch and gyro routing
  • ■C++ fixed-step simulation and native host tests
  • ■Offline loop experiments and rapid UI validation

Outcome: stable input and systems contract

TRANSFER THE CONTRACT →

Unreal

Production path

  • ■3D capsule movement, spring-arm camera, real collision
  • ■Authored meshes, animation, VFX, LOD, and forest world
  • ■Server-ready combat, survival, weapons, and world systems

Outcome: measurable, player-facing 3D vertical slice

Decision rule

Do not mistake the 2D-ish Android renderer for the final 3D game. Freeze the established input and progression semantics, then validate them in one authored Unreal forest micro-region on a real Android device.
