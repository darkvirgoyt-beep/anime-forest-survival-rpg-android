PRIORITY ORDER
08 / Recommended sequence

DEPTH BEFORE SCALE

The roadmap is not a feature wish list. Each step removes a production risk that would make the next step more expensive.

01

Freeze the contract

Lock product name, device tiers, input actions, reference resolution, and authority boundaries.

02

Build the Unreal 3D slice

Ship one forest micro-region with real camera, collision, hero, target dummy, and Android device proof.

03

Make progression authoritative

Version inventory, equipment, XP, quests, and saves so UI state becomes durable gameplay state.

04

Complete the combat loop

Add enemy AI, telegraphs, player damage, stagger, death, respawn, and meaningful loot.

05

Reduce field HUD density

Keep combat essentials visible; move craft, inventory, and settings into contextual or pause layers.

06

Establish content production

Run original asset, animation, audio, localization, LOD, and device-profile pipelines.

07

Add co-op after proof

Only then validate server authority, reconnect, shared world mutations, and replicated rewards.

■Decision rule

Do not expand placeholder maps, menus, or item catalogs until one real region, one threatening enemy, one build-changing item, and one save/reload cycle are fun and measured.
